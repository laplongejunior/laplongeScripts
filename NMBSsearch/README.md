An utility script that's going to be VERY localised and specific
When looking for train lines on the belgiantrain website, it adds to the line details some quick-links to the other search pages
When necessary, it also adds client-side parameters to autofill some fields (but some are too complex to handle)

!When the script autofills a station name, you must click on it and remove one character to select it through their search engine!
The station's NAME isn't enough, the field needs to point to the search result with that name
(But hey at least it avoids some copy-pasting...)

- For each search, a link to the TrainPlus simulator to calculate prices
- For each train on the trip, a direct link to the complete itinerary (but that page only supports looking into yesterday or two days in the future)
- - No custom scripts needed on THAT page tho, as it handles pure-text parameters natively, kudos to NMBS for that one! :D  
- For each train on the trip, a link to the real-time station viewer (useful in case you need to estimate the scope of details : is it ONE train or is the whole station clogged?)
- And a direct link to the BeluxTrain AWESOME fan database to be able to see a train's room composition depending on dates, seasons, etc.
